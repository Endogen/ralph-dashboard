# Follow-up review of September 20 changes

Reviewed `4008e38` and `081095e` against the previously verified `f0ed7d1` baseline. The byte-preserving wizard changes, lazy chart loading, dependency pins, process reaper references and empty activity fallback are retained. Nine issues needed follow-up:

| Finding | Correction |
| --- | --- |
| Concurrent login requests all passed the failed-attempt check before bcrypt finished | Reserve an in-flight slot before starting authentication and release it in `finally` |
| Missing/null credential-version claims were accepted when the credentials file was absent | Reject tokens without configured credentials; do not mint tokens without credentials |
| Pruning an old but held lock allowed a second writer to enter through a new inode | Lock before pruning; validate the named inode after acquisition and retry if it was replaced |
| A persistent runner log handle continued writing to a renamed file after rotation | Reopen when the log path is removed or points to a different inode |
| A final log burst larger than the drain budget could leave its tail unread indefinitely | Schedule bounded continuations and alternate them with other file events |
| Generation cleanup could leave children alive after the session leader exited | Terminate the original process group established by `start_new_session=True` |
| Refresh HTTP 503 responses signed users out, and network retries reused a rejected socket token | Preserve credentials on transient errors and retry refresh before creating another socket |
| Fresh CI dependency resolution treated new upstream releases as a stale lock | Seed checks with committed pins; expose explicit `--check` and `--upgrade` modes |
| The stated weekly audit ran on every push and masked failures with `continue-on-error` | Separate scheduled/manual audits into their own failing workflow; audit committed Python requirements independently of the tool environment |

## Verification

- Backend regression suite passes locally on macOS; the locked Linux environment also passes the application suite.
- Added regressions for concurrency, missing credentials, held and replaced lock inodes, log rotation, log continuation fairness, and orphaned generation children.
- A real uv resolver test uses local fixture wheels to prove new releases preserve valid pins, incompatible manifest changes fail, and checks leave the original files unchanged. It skips when uv is unavailable; the Linux validation job installs uv before running tests.
- Frontend: 22 tests pass, including HTTP refresh behavior and a mounted WebSocket hook surviving an outage. Lint, TypeScript, production build and bundle budgets pass.
- Container build and installed-artifact smoke tests pass: packaged runner, Codex/Claude CLI startup, HTTP health endpoint and frontend serving.
- Python locked-requirements audit and npm audit report no known vulnerabilities.
- Existing upstream Starlette/AnyIO deprecation and optional Monaco chunk-size advisories remain visible.

Paid provider requests were not part of this review; runner integration uses executable fixtures.
